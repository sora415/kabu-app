# きせつ観光ナビ

都道府県・日にち・天気を選ぶと、その季節にぴったりの観光スポットと
ご当地グルメを教えてくれる、1ファイル完結のWebアプリです。

※ このフォルダは株アプリ（kabu-app 本体）とは独立した別アプリです。

## 使い方

`kanko-navi/index.html` をブラウザで開くだけで動きます
（インターネット接続は、文字フォントの読み込みにのみ使います）。

1. 都道府県を選ぶ（全国47都道府県）
2. 日にちを選ぶ（季節のおすすめに反映されます）
3. 天気を選ぶ（雨・雪なら屋内スポットを上に表示）
4. 「おすすめを見る」を押す

結果はカテゴリ（歴史・自然・温泉・グルメなど）で絞り込めます。

## データの増やし方

`index.html` の中ほどにある `const DATA = { ... }` を編集します。
すぐ上に日本語のコメントで追加方法を書いてあります。

- 県を足す　　→ `"県名": { spots: [...], foods: [...] }` を追加
- スポットを足す→ その県の `spots` に `{ name, cat, season, in, desc, why }` を追加
- ご飯を足す　→ その県の `foods` に `{ name, tag, desc, season(任意) }` を追加

`season` は `"spring" / "summer" / "autumn" / "winter"`、通年は `"all"`。
`in: true` は屋内・雨でも楽しめるスポットを表します。
