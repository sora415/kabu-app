# 🌱 補助金ウォッチ（淡路島 農業・飲食・宿泊）

淡路島の事業者むけに、補助金・助成金の情報を **集めて・整理して・締切を知らせる** かんたんなアプリです。
株アプリと同じ仕組み（Python の小さなサーバー ＋ スマホに入れられる Web アプリ）で動きます。

## できること

| 画面 | できること |
|------|-----------|
| **一覧** | 登録した補助金を、締切が近い順に表示（近いものは色でお知らせ） |
| **新着** | 市役所・県などの公式ページに出た「補助金っぽい新着リンク」を自動で検知 |
| **情報源** | 自動チェックする公式ページを追加・削除。「今すぐチェック」も押せる |
| **週次レポート** | 今週の新規ぶん＋締切が近いものを文章にまとめる（コピーして note に貼れる） |
| **設定** | 締切・新着を知らせるプッシュ通知のオン／オフ |

## ⚠️ 大事な注意（信用を守るため）

- **申請書類の作成代行は行政書士の仕事です。** このアプリは「情報の整理と提供」だけに使ってください。
- **金額・締切の間違いは一番の信用問題です。** 新着で見つけたものは、必ずリンク先の**公式ページで中身・金額・締切を確認してから**登録してください。登録時に「確認日」が自動で入ります。

## うごかし方（パソコンで試す）

```bash
cd hojokin-app
python3 server.py
```

ブラウザで `http://localhost:8810` を開きます。
（通知の送信まで試したいときは、先に `pip install pywebpush` をしてください。通知なしでも一覧・新着・レポートは使えます。）

## スマホで使う / 人に見せる（Render 無料プラン）

株アプリと同じ Render に、**2つ目のサービス**として出せます。

1. Render で **New → Blueprint**（または Web Service）を選ぶ
2. このリポジトリを指定し、**Root Directory を `hojokin-app`** にする
3. 下の環境変数を設定（通知を使う場合）

| 環境変数 | 役割 |
|----------|------|
| `VAPID_PUBLIC` / `VAPID_PRIVATE` | 通知の鍵（空ならサーバーが自動生成。ただし無料プランは再デプロイで消えるので、固定したいなら設定） |
| `VAPID_SUBJECT` | `mailto:あなたのメール` |
| `CHECK_TOKEN` | `/api/check` を外部から叩くときの合言葉（任意） |
| `CHECK_INTERVAL` | 自動チェックの間隔（秒）。既定 3600（＝1時間） |

スマホでは、ブラウザで開いて「**ホーム画面に追加**」→ アプリとして開く → 設定タブで「通知をオンにする」。
（iPhone は、ホーム画面に追加したアプリから開かないと通知が使えません。）

> 無料プランはしばらくアクセスが無いとサーバーが眠ります。眠っている間は自動チェックも止まります。
> 確実に定期チェックしたい場合は、外部の無料 cron（例：cron-job.org）から
> `https://あなたのアプリ/api/check?token=合言葉` を1時間おきに叩くようにします。

## 仕組みのメモ（あとで自分でいじるとき用）

- `server.py` … 本体。情報の保存・自動チェック・通知・レポートづくり
- `index.html` / `app.js` / `style.css` … 画面
- `manifest.json` / `sw.js` / `icons/` … スマホアプリ化（PWA）の設定
- データは `subsidies.json` などの JSON ファイルに保存（`.gitignore` 済みなので公開されません）

### 自動検知の考え方
全自動で金額や締切まで読み取るのは壊れやすいので、自動部分は
**「公式ページに補助金っぽい新着リンクが出たら検知して知らせる」** までにしています。
金額・締切の確定は、人が公式ページで確認して登録する流れです（＝信用を守る）。

拾うキーワードや間隔は `server.py` の上のほう（`SOURCE_KEYWORDS` / `REMIND_DAYS` / `CHECK_INTERVAL`）で変えられます。
