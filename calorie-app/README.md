# 📷 写真でカロリー推定アプリ

食事の写真を選ぶと、AI（Claude）が写っている食べ物とだいたいのカロリーを推定してくれる、かんたんな Web アプリです。スマホ・PC どちらのブラウザでも使えます。

> ⚠ **大事なこと**: 写真だけで正確なカロリーは測れません。このアプリが出す数字は「AIによる目安の推定値」です。ダイエットの参考程度にご利用ください。

---

## 仕組み（初心者向けのざっくり説明）

1. ブラウザの画面で食事の写真を選ぶ
2. その写真がこのアプリの「サーバー」に送られる
3. サーバーが写真を **Claude（画像を理解できるAI）** に見せて、「何の料理か・カロリーはどれくらいか」を推定してもらう
4. 結果が画面に表示される

つまり **画面（フロント）** と **サーバー（バック）** の2つでできています。

---

## 使うために必要なもの

1. **パソコン**（Windows / Mac どちらでもOK）
2. **Python 3**（多くのMacには最初から入っています。無ければ https://www.python.org からインストール）
3. **Anthropic の API キー**（Claude を使うための鍵。下で取得方法を説明します）

---

## ① API キーを取得する

1. https://console.anthropic.com にアクセスしてアカウントを作成（無料で始められます）
2. ログイン後、「API Keys」から新しいキーを作成
3. `sk-ant-...` で始まる文字列が表示されるのでコピーして控えておく

> 💡 API キーは「パスワード」のようなものです。他人に見せたり、ネットに公開したりしないでください。

---

## ② アプリを動かす

ターミナル（Mac）またはコマンドプロンプト（Windows）を開いて、順番に入力します。

```bash
# 1. このフォルダに移動
cd calorie-app

# 2. 必要なライブラリをインストール（最初の1回だけ）
pip install -r requirements.txt

# 3. API キーを設定する（"sk-ant-..." の部分は自分のキーに置き換える）
#    Mac / Linux の場合:
export ANTHROPIC_API_KEY="sk-ant-ここに自分のキー"
#    Windows (コマンドプロンプト) の場合:
#    set ANTHROPIC_API_KEY=sk-ant-ここに自分のキー

# 4. サーバーを起動
python3 server.py
```

`カロリー推定アプリを起動しました → http://localhost:8900` と表示されたら成功です。

## ③ ブラウザで使う

ブラウザで **http://localhost:8900** を開きます。

1. 「写真をえらぶ / 撮影する」を押して食事の写真を選ぶ
2. 「この写真を解析する」を押す
3. 数秒待つと、食べ物ごとのカロリーと合計が表示されます

止めたいときは、ターミナルで `Ctrl + C` を押します。

---

## こまったときは（よくある質問）

| 症状 | 原因と対処 |
| --- | --- |
| `APIキーが設定されていません` と出る | ②の手順3のキー設定をやり直してください（ターミナルを開き直すと消えるので、その都度設定が必要です）。 |
| `pip: command not found` | `pip3` に置き換えて試してください。 |
| `python3: command not found` | Python がインストールされていません。https://www.python.org から入れてください。 |
| 解析が遅い / 料金が気になる | 下の「モデルの変更」を参照。安く速いモデルに切り替えられます。 |

---

## モデルの変更（上級者向け・任意）

既定では精度の高い `claude-opus-5` を使っています。**もっと安く・速く**したい場合は、起動前に環境変数で切り替えられます。

```bash
# 例: 低コストで軽いモデルに変更
export CALORIE_MODEL="claude-haiku-4-5"
python3 server.py
```

- `claude-opus-5` … 精度が一番高い（既定）
- `claude-sonnet-5` … バランス型
- `claude-haiku-4-5` … 速くて安い（精度はやや下がる）

## 注意事項

- カロリーは推定値です。医療・治療目的には使わないでください。
- API の利用にはあなたの Anthropic アカウントの料金がかかります（写真1枚あたり数円程度が目安）。
