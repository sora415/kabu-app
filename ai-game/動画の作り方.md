# 「AIで作ったゲームをプレイしてみた！」動画 完全ガイド

このファイルだけ見れば、動画を最後まで作れるようにまとめました。
上から順にやればOKです。初心者向けに、専門用語はなるべく使っていません。

---

## 0. まず準備するもの

- **ゲームのURL**（下の「ゲームを開く」から開けます）
- **録画する機械**：パソコン か スマホ（どちらでもOK）
- **声を入れたい場合**：マイク（スマホ・PC内蔵でもOK。なくても字幕だけでいけます）

### ゲームを開く
Claudeの画面の右側に表示されているゲーム（「ネオン・ダッジ」）を使います。
- **START** を押すとゲーム開始
- **PC**：マウスで光るキューブを動かして、赤い図形を避ける
- **スマホ**：画面を指でなぞって避ける
- **ギリギリで避ける**と「GRAZE（グレイズ）」というコンボが入って点数アップ → ここが見せ場です！

## 1. 動画のタイトル案（サムネにも使えます）

好きなものを1つ選んでください。数字やカッコで「ツッコミどころ」を作ると伸びやすいです。

1. **【AI自作ゲーム】AIにゲーム作らせたら神ゲーできたwww**
2. **AIに「面白いゲーム作って」って言った結果→プレイしてみた**
3. **【検証】AIが作ったゲーム、どこまで遊べるのか？**
4. **1ミリも自分でコード書いてないゲームで本気を出す**
5. **AI製アーケードゲームでハイスコア何点出せる？**

### サムネに入れる文字（大きく2〜3語だけ）
- 上段：**AIにゲーム作らせた**
- 下段：**まさかの神ゲー…？**
- 右下に小さく：スコア数字（例：`BEST 1200`）を入れると「ちゃんと遊んでる感」が出ます

> サムネのコツ：文字は大きく・短く・2色まで。自分の驚いた顔のアップがあると最強です。

## 2. 動画の構成（台本）

全体で **3〜6分** が目安。カッコ内は「話すこと／字幕に出すこと」です。
声を入れない場合は、カッコ内をそのまま字幕にすればOKです。

### ① オープニング（10〜20秒）
- （話す）「どうも！今日はAIに作ってもらったゲームを実際にプレイしていきます」
- （画面）ゲームのタイトル画面（ネオンの「ネオン・ダッジ」）を映す
- （字幕）**AIが作ったゲームをガチプレイ**

### ② ゲーム紹介（20〜40秒）
- （話す）「ルールはシンプル。この光るキューブを動かして、落ちてくる赤い図形を避けるだけ」
- （話す）「でもギリギリで避けると"GRAZE"ってボーナスが入るらしいんですよ。危ない橋を渡るほど高得点」
- （画面）START前の説明画面をゆっくり見せる

### ③ 1回目プレイ（30秒〜1分）※様子見
- （話す）「とりあえず1回やってみます」
- ここで**わざと早めにやられてもOK**。「え、むずっ！」というリアクションが面白い
- （字幕）やられた瞬間に **「は、早すぎる」** などツッコミ字幕

### ④ 本気プレイ（1〜2分）※メイン
- （話す）「コツ掴んできた。今度は本気で」
- GRAZEコンボが連続した所、シールド（水色の◇）やスロー（金色の◇）を取った所は**盛り上げポイント**
- （字幕）コンボ中に **「ギリギリィィ！」** 「天才かもしれん」など
- スコアが伸びたら数字を指差す／拡大すると分かりやすい

### ⑤ ハイスコア挑戦＆オチ（30秒〜1分）
- （話す）「最後、自己ベスト更新いきます」
- 成功 → **NEW BEST** 表示をしっかり映す（ここが一番の見どころ）
- 失敗 → 悔しがるリアクションでオチにする

### ⑥ まとめ（10〜20秒）
- （話す）「AIが作ったとは思えないクオリティでした。意外とハマるのでおすすめです」
- （話す）「このゲームもう1本作ってほしいとか、こういうの見たいってのがあればコメントで！チャンネル登録もぜひ」
- （字幕）**高評価・チャンネル登録お願いします🙏**

## 3. 撮影手順

### ▼ パソコンの場合（Windows / Mac 共通の考え方）

1. ゲームのURLをブラウザ（Chromeなど）で開く
2. 画面録画ソフトを起動する
   - **Windows**：キーボードの `Windowsキー + G` で「Xbox Game Bar」が開きます → ●（録画）ボタンで開始／停止
   - **Mac**：`Shift + Command + 5` を押す → 「収録」を選んで範囲を決めて録画
   - 慣れてきたら無料ソフト **OBS Studio** が高機能でおすすめ
3. **声も録りたい場合**：録画ソフトの「マイク」をオンにする
4. 録画スタート → ゲームをプレイ → 録画ストップ
5. 動画ファイルが保存される（Windowsは「キャプチャ」フォルダ、Macはデスクトップ）

> コツ：ブラウザを**全画面（F11）**にすると、余計なものが映らずキレイです。

### ▼ スマホの場合

- **iPhone**：設定 → コントロールセンター →「画面収録」を追加 → 画面右上から下にスワイプして録画ボタン（◉）を押す
- **Android**：画面を上から下にスワイプ → クイック設定の「スクリーンレコード／画面録画」をタップ
- マイクをオンにすると自分の声も入ります
- ゲームのURLをスマホのブラウザで開いて、録画しながらプレイ

> スマホは**横向き**にすると画面が広く使えて見やすいです。

## 4. 編集のコツ（初心者向け・最低限でOK）

編集ソフトの例：
- スマホ：**CapCut**（無料・簡単・日本語）
- PC：**CapCut（PC版）** か、Windows標準の **Clipchamp**、Mac標準の **iMovie**

やると一気に「動画っぽく」なる3つ：
1. **いらない部分をカット**（長い待ち時間、しゃべり間違いなど）
2. **字幕を入れる**（上の台本のカッコ内をそのまま使えます）
3. **やられた瞬間に効果音**（「ドン！」などCapCutの無料素材でOK）

音楽：著作権フリーのBGMを使う（CapCut内の「おすすめ」や、YouTubeオーディオライブラリ）。
※ 有名な曲をそのまま使うと公開できないので注意。

## 5. 公開の流れ

1. 編集した動画を書き出す（保存する）
2. YouTubeアプリ or サイトで「アップロード」
3. タイトル（上の案から）・サムネ・説明文を入れる
4. 説明文の例：
   ```
   AIに作ってもらったゲーム「ネオン・ダッジ」を実際にプレイしてみました！
   マウスや指で動かして、落ちてくる図形を避けるシンプルな避けゲー。
   ギリギリ回避のGRAZEコンボがクセになります。

   #AI #自作ゲーム #ゲーム実況
   ```
5. 公開！
